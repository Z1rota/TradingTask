# TradingTask

Тестовое задание для СПВБ. В проекте реализована упрощённая торговая система для покупки и продажи акций.

Пользователь может открыть счёт, пополнить его тестовыми деньгами и бумагами, 
выставить заявку. Система находит встречные заявки и заключает сделки. 
Через API можно посмотреть стакан и историю своих операций.

## Сущности

- `User` хранит данные пользователя для регистрации и входа.
- `Instrument` описывает акцию. У неё есть код, размер лота, шаг цены и валюта расчётов.
- `Account` представляет счёт пользователя в одной валюте. Счетов может быть несколько, в том числе в одинаковой валюте.
- `Position` хранит количество бумаг конкретного инструмента на счёте и их зарезервированную часть.
- `Order` содержит сторону заявки, цену, количество лотов и оставшийся объём.
- `Trade` хранит результат исполнения двух встречных заявок.

## Как проходят торги

Количество в заявке задаётся в лотах, цена указывается за одну бумагу. На позициях учитывается количество самих бумаг.

Сначала исполняется заявка с лучшей ценой. При равной цене приоритет получает более ранняя заявка. Цена сделки берётся из заявки, которая уже была в стакане. Исполнение может быть частичным.

При создании заявки система резервирует деньги или бумаги. 
При отмене освобождается резерв оставшегося объёма. 
Замена отменяет старый остаток и создаёт новую заявку с новым приоритетом.
Если заменить заявку не получилось, старая остаётся активной.

Сделки между счетами одного пользователя запрещены. 
Если очередь дошла до собственной заявки, система отменяет остаток входящей заявки.

## Запуск

Для запуска нужны JDK 17 и Docker. Команды ниже выполняются в PowerShell из корня проекта.

Создайте файл `.env` со случайным ключом для JWT. Формат файла есть в `.env.example`.
Поднимите базу данных и запустите приложение.

```powershell
docker compose up -d
mvn spring-boot:run
```


Для работы с API сначала зарегистрируйтесь через `POST /api/auth/register`, затем войдите через `POST /api/auth/login`. Полученный токен передавайте в заголовке `Authorization: Bearer <token>`.

Тестовое пополнение доступно через `POST /api/dev/funding`. Для пополнения, создания и замены заявки нужен заголовок `Idempotency-Key`. Повтор запроса с тем же ключом и параметрами не выполняет операцию ещё раз.

## Тесты

```powershell
mvn clean verify
```

Docker должен быть запущен. Тесты сами поднимают отдельную базу в контейнере 
и запускают приложение на свободном порту. 
Они проверяют расчёты, порядок исполнения, отмену и замену заявок, 
повторные и конкурентные запросы, стакан и доступ к данным.
